# 정신과 의사의 모험 — JMS

> *Ace Attorney(역전재판)* 메커닉을 정신과 진료로 옮긴 **진료 추리 어드벤처 게임**

**▶ 지금 플레이: https://emptypizza.github.io/jms-game/**

신입 정신과 의사 **이현종**이 되어 환자의 말에서 단서를 모으고, 의료지식백과로 병명·처방을 확인해 정확한 진단을 내리는 웹 게임입니다. PixiJS 7.4.2 / WebGL 기반의 단일 HTML 파일로 동작하며, 별도 설치 없이 브라우저만 있으면 바로 즐길 수 있습니다.

---

## 게임 소개

- **장르**: 진료 추리 어드벤처 (역전재판 스타일)
- **배경**: 제일종합병원 정신건강의학과, 2018년 3월 8일
- **플레이타임**: 약 3~5분 (CASE 1, 직선형)
- **언어**: 한국어

### 등장인물
| 역할 | 이름 | 설정 |
|------|------|------|
| 주인공(플레이어) | **이현종** | 첫 출근한 정신과 의사 |
| 보조/튜토리얼 | **한석지** | 간호사. 진료 시스템 안내 및 피드백 |
| 환자 (CASE 1) | **이승헌** | 남 27세, 고시생. 주호소 "우울" |

## 플레이 방법

1. **진료 시작** — 타이틀에서 "진료 시작하기"를 누르고 간호사의 안내를 듣습니다.
2. **진술 청취** — `◀ ▶` 로 환자의 대사를 살펴보며 증상을 파악합니다.
3. **단서 확보** — 증상이 담긴 대사에서 **🔍 단서 확보** 버튼을 눌러 단서 토큰을 모읍니다.
4. **백과 조회** — 증상 토큰을 **📖 의료지식백과**에 드래그&드롭하면 병명·처방 키워드가 해제됩니다.
5. **기록부 작성** — 모은 토큰을 **환자기록부**의 치료/진단/처방 슬롯에 끌어다 놓고, 심각도를 선택합니다.
6. **진단 제출** — 모든 항목이 맞으면 `APPROVED` 스탬프와 함께 케이스 클리어!

### 승리 조건
- 증상 단서 **3개 이상** 수집
- 진단: **우울증**
- 심각도: **초기**
- 처방: **파란약**

> 하나라도 틀리면 "오진!" 피드백 후 무한 재시도할 수 있습니다.

## 조작

- **마우스 / 터치** 기반 (키보드 입력 없음, 모바일 호환)
- 클릭/탭: 대화 진행
- `◀ ▶`: 환자 진술 순회
- 드래그&드롭: 단서 토큰을 백과·기록부 슬롯에 배치

## 기술 스택

| 영역 | 구현 |
|------|------|
| 렌더링 | PixiJS 7.4.2 (인라인) / WebGL |
| 캐릭터·배경 | Base64 PNG 스프라이트 |
| UI·이펙트 | PixiJS Graphics 프로시저럴 생성 |
| 애니메이션 | 자체 트윈 엔진 (Ease 함수 기반) |
| 사운드 | Web Audio API 절차적 합성 (효과음 실시간 생성) |
| 폰트 | Google Fonts (Gothic A1 · Jua · Do Hyeon · Black Han Sans) |
| 해상도 | 가상 1024×728, 윈도우에 맞춰 스케일 |

모든 라이브러리·이미지·사운드가 `index.html` 한 파일에 인라인되어 있어 외부 의존성(폰트 CDN 제외) 없이 동작합니다.

## 구성 / 향후 계획

- **CASE 1 · 2 · 3** 세 편을 메인 화면(`index.html`)에서 선택해 플레이합니다.
- CASE 1·2는 정신과 진료 추리(PixiJS), CASE 3 「공정재판」은 정신과 의사가 **재판장**이 되어 법정을 운영하는 편(Canvas2D)입니다.
- 메인 → 각 편, 각 편 → 「← 메인」 링크로 오갈 수 있습니다. (`index.html?` 딥링크: `jms_cases.html?case=1|2`)
- 다음 편 예고: **CASE 4 「기억하지 못하는 증인」**.
